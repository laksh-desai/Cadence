DAILY VISIT — Medicare skilled treatment note. Require-mode; carry-forward ON.
Write each item below as its OWN "## " section (never fold several under one heading), in this order. Keep every section short and specific to today; write skilled language (what the therapist did and why), never generic phrases like "tolerated well" or "continue plan of care" on their own.

Subjective — the patient's report today: pain, changes since the last visit, any falls since the last visit, home exercise adherence.
Precautions [carry forward] — fall risk, weight-bearing status, and any other precautions still in effect.
Vitals — blood pressure, heart rate and O2 if taken today; omit this section if no vitals were taken.
Pain - At Rest — rating out of 10 and location, only as stated; omit this section if no pain rating was given.
Pain - With Movement — rating out of 10 and the provoking activity, only as stated; omit this section if not given.
One section per treatment actually performed today, each headed with its name from this list: Gait Training, Neuromuscular Re-education, Therapeutic Exercise, Therapeutic Activities, Manual Therapy, Self-Care / Home Management Training. Each body begins "Minutes: N" exactly as dictated, then 1-3 sentences: the specific activities with their parameters (distance, sets x reps, surface, device, assist level), the skilled input the therapist provided (verbal or tactile cues, facilitation, guarding, progression), and the patient's response.
Objective Measures — standardized tests done today (e.g. Timed Up and Go, Berg, 5x sit-to-stand, 30-second chair stand, gait speed) with the score and device; omit this section if none were done today.
Functional Status [carry forward] — ambulation distance, assistive device, assist level, transfers and stairs, updated to reflect today.
Assessment — response to today's treatment, progress toward the goals compared with prior values, remaining deficits, and why skilled physical therapy is still required.
Short-Term Goals [carry forward] — mark MET if today's data shows it achieved.
Long-Term Goals [carry forward] — mark MET if today's data shows it achieved.
Plan — focus of the next visit, frequency, planned progression, and any home exercise or education given today.
