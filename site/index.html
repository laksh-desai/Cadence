Before you install

Cadence needs two free things installed first. It will tell you if either is missing.

  • Python 3.12 — python.org. Tick “Add python.exe to PATH” during setup.
  • Ollama — ollama.com. This runs the language model locally.

You'll also want roughly 30 GB free and a machine with 16 GB of memory. Generating a note takes several minutes — Cadence writes it in the background so you can carry on.

Installing

Unzip the download, then in that folder run:

powershell -ExecutionPolicy Bypass -File .\setup.ps1

It installs everything else, downloads the models, and puts a shortcut on your desktop. Re-running it is safe — it never touches notes or keys that already exist.

Updating later

python scripts\update.py --check

Shows what a new version would change before anything is downloaded. Nothing updates by itself, your notes are backed up first, and the previous version stays on disk so an update can be undone immediately.

What's in this version

Please read

Cadence drafts; you sign. Every note is a draft to review and correct. The model can be wrong, and it is not certified for clinical use.

Your notes live only on this computer, in one encrypted file. If the laptop dies without a backup, they are gone. Back up to an encrypted USB drive, and test a restore occasionally — scripts\backup.py does both.

Billing codes are switched off until the code tables have been reviewed by a certified coder. A confidently-wrong code is worse than no code. Cadence's Status page says so plainly, and they switch on by themselves once the review is done.

Cadence is a local, offline tool. It has no accounts, no telemetry, and no server.
The only thing it ever fetches is the update file that populates this page.
