Cadence. Physical therapy notes, dictated.
Prototype

Demo only — use fake patients. This is a UX reference for the Cadence workflow: it does not generate notes and sends nothing anywhere. Note generation runs entirely on your own computer in the installed Cadence app, which saves to an encrypted local file — nothing ever leaves the machine. Patients/files here live only for this session (they reset on reload) and nothing here is private or HIPAA-compliant. Do not enter real patient details.
