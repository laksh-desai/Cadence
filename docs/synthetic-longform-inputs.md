# Synthetic long-form dictations (ScopeHealth-style)

**Fully synthetic. No PHI.** These are fictional-patient dictations written to match the *length,
thoroughness, and spoken style* of a real long-form outpatient-PT initial evaluation (the way a
therapist dictates a full eval in ScopeHealth) — **not** copied from any real transcript. No real
names, MRNs, or dates tied to a real person. Each is a single continuous text chunk (~1000+ words),
**no timestamps**, with the natural disfluencies MedASR captures: fillers (um, uh), mid-word
self-corrections, checklist "…, yes/no" answers, and template field labels read aloud.

**PHI guardrail (unchanged):** never paste a REAL transcript into Claude/any cloud — de-identify
first. See [synthetic-data-plan.md](synthetic-data-plan.md). These stress the long-dictation path
(rule 16 condensing), the full rule-15 section coverage, eval-complexity flagging, and code
capture-vs-author (rule 12): some dictate codes explicitly (must be captured), most state none
(must NOT be authored).
