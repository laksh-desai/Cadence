# Cadence 1.0.0

First release. Everything runs on this computer — patients, dictation, transcription, note
generation, and storage. Nothing is sent anywhere.

## What it does

- **Dictate a session four ways** — type it, talk to it, upload a recording, or record the whole
  visit live. All transcription happens on this machine.
- **Fills your note templates** — three built in (Initial Evaluation, Initial Evaluation Updated,
  Follow-Up Visit), and you can add or edit your own in the Templates tab.
- **Flags what's missing instead of inventing it.** Anything Cadence could not find in what you
  said is marked in amber for you to fill in. It will not make up a measurement.
- **Carries the right sections forward** on a follow-up, and updates them against today's visit.
- **Notes keep writing while you move on.** A note takes several minutes on this hardware, so it
  runs in the background — start one, go see the next patient, and review both later. The "Notes
  in progress" strip tracks them from any tab.
- **Copy for Office Ally** buckets a finished note into Subjective / Objective / Assessment / Plan.

## What is switched OFF in this release

**Billing code suggestions (CPT and ICD-10).** The code tables have not yet been reviewed by a
certified coder, and a confidently-wrong code is worse than no code — so Cadence hides them rather
than showing you something it cannot stand behind. The Status tab says so plainly.

They switch on by themselves once the tables are signed off; nothing to reinstall.

## Please read

- **Every note is a draft.** Cadence writes, you review and sign. It can still get things wrong,
  and the underlying model is not certified for clinical use.
- **Back up.** Your notes exist only on this machine, in one encrypted file. Run
  `scripts/backup.py` to a USB drive — and `restore --dry-run` occasionally to prove the backup
  actually works.
- Recording a whole visit needs the patient's consent, and the live transcript does not separate
  speakers yet.

## Installing

Unzip, then from the folder:

    powershell -ExecutionPolicy Bypass -File .\setup.ps1

It checks for Python and Ollama, installs everything else, pulls the models, and puts a shortcut
on the desktop. Full walkthrough: `docs/shipping.md`. Before real patient data, do the device
hardening in `docs/device-safeguards-checklist.md`.
