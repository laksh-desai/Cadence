The outline Cadence fills for each note type — read it while you dictate so you cover everything, or edit it to change what the note asks for. Editing an outline changes what the local model is told to produce; every note is still clinician-reviewed. Duplicate a template to start a variant, and reset any built-in back to its original.

Billing Accuracy Evals

Measure how well Cadence reads billing codes, treatment minutes, and units out of a dictation. Cadence writes realistic fake sessions together with the right answers, runs them through the real pipeline, and scores what it got. No real patient data is involved and nothing is saved to any patient's file. Generating samples is instant; running a sweep uses the local model and takes roughly a minute or two per note, during which note generation will be slow.
